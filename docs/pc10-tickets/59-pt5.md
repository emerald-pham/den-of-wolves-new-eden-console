# PT5: Provide compact runtime diagnostics

**Existing prompt scope:** P651 proof execution support; P660 owned runtime inspection.

**Playable release:** [PC10.4 — Fair automatic actions and receipts](../PRODUCT_MILESTONES.md#pc10-smaller-playable-releases--2026-10-16).

**Status:** ready-for-agent for this approved tooling repair; catalog completion is unchanged.

**Planning source:** [Approved proof-tooling repairs](../PRODUCT_MILESTONES.md#approved-proof-tooling-repair-tickets--2026-10-16).

**What to build:** An owner can assess a run's process and port state from concise diagnostics, with detailed evidence retained on disk, instead of repeatedly reading whole-machine process listings.

**Blocked by:** None (can start immediately). Existing recorded runtime ownership is sufficient; PT4 is not a prerequisite.

## Acceptance criteria

- [ ] Extend existing runtime helpers to inspect recorded owned processes, their descendants and allocated ports, returning a concise result and detailed evidence location.
- [ ] The summary identifies the original result, remaining owned processes/listeners and incomplete cleanup; quiet or truncated console output cannot imply successful return.
- [ ] Preserve the primary test or gameplay failure when diagnostics or cleanup also fail, and retain detailed failure evidence on disk.
- [ ] Foreign or ambiguous ownership remains explicit and grants no authority to stop a process or release a reservation. Missing ownership evidence cannot produce a clean-return claim.
- [ ] Focused fixtures cover clean return, a live descendant, an occupied owned port and diagnostic failure. Normal console output stays scoped to the run rather than printing the host process table.

## Testing and handoff boundary

Observe a meaningful failing summary/ownership regression before implementation. Reuse current runtime records and process helpers with isolated fixtures and small disposable owned processes; this brief adds no evidence schema, measurement system or gameplay acceptance requirement.

Return the adopted diagnostic entry points, retained evidence examples and focused results. The final owner still verifies complete resource return under the existing policy.
